# validate-rationales

Purpose:
Improve rationale quality so explanations actually teach.

Workflow:
1. Review the right answer explanation.
2. Check whether it explains why the right answer is right.
3. Check whether the wrong answers are meaningfully distinguished when useful.
4. Remove vague wording and overclaiming.
5. Add safety, prioritization, monitoring, contraindication, or adverse effect context when relevant.
6. Keep the explanation concise enough for study use.

Standards:
1. Clear.
2. Clinically grounded.
3. Fair.
4. Educational.
5. Original wording.

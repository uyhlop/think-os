# teach-and-handoff

Purpose:
Make the work understandable and repeatable for the buyer.

Workflow:
1. Explain the goal in plain language.
2. Explain what part of the repo is being changed.
3. Do the change or guide the workflow.
4. Verify it.
5. Explain what the user should learn from this example.
6. Provide the next best repeatable step.

Standards:
1. Teach without overexplaining.
2. Keep explanations practical.
3. Focus on repetition and ownership.
4. Make the buyer feel they received a real system, not random prompting.

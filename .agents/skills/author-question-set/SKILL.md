# author-question-set

Purpose:
Create original nursing question sets with clear educational value.

Workflow:
1. Identify the source topic and learner level.
2. Decide what the student should actually learn.
3. Write original stems and answer choices.
4. Keep distractors fair and clinically meaningful.
5. Add concise rationales that teach practical distinctions.
6. Check for safety, prioritization, contraindications, monitoring, and adverse effect logic when relevant.
7. Return the material in a format the repo can use.

Standards:
1. Original wording only.
2. No copied exam bank phrasing.
3. Avoid trivia.
4. Teach the why, not just the what.
5. Keep level appropriate for early nursing students unless specified otherwise.

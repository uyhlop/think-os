# ThinkRN Plan.md

## Current operating plan

### Milestone 1
Establish the Codex operating system inside the repo.
Success means AGENTS.md, Prompt.md, Plan.md, Status.md, custom agents, and reusable skills exist and are coherent.

### Milestone 2
Audit the existing repo and identify the true state of the product.
Success means a concise baseline assessment exists in Status.md with the highest value next step.

### Milestone 3
Build or improve the smallest complete student facing milestone.
Preferred target:
1. student dashboard,
2. topic cards,
3. recent performance section,
4. missed questions filter,
5. mobile friendly layout,
6. empty states.

### Milestone 4
Improve content operations.
Success means there is a clear workflow for authoring question sets and validating rationales.

### Milestone 5
Improve premium teaching flow.
Success means the repo supports the 100 dollar delivery with a clear handoff prompt and teaching mode.

### Milestone 6
QA and release discipline.
Success means repeatable verification and release checks are present.

## Decision rules
1. Choose the highest value smallest complete step.
2. Avoid broad refactors until the core flow is usable.
3. Prioritize clarity over cleverness.
4. Ship improvements that can be demonstrated to a real buyer.

# Think OS Prompts

This folder organizes the operating prompts that Ray uses across the Think ecosystem. Each prompt serves a different role in the agent rotation and is preserved here as a reusable reference.

| File | Purpose |
|---|---|
| `claude_code_prompt.md` | Continue-mode engineering prompt for product development and founder ops integration in ThinkRN |
| `codex_ops_prompt.md` | Recurring automation prompt for inbox, reporting, campaign, and smoke-test workflows |
| `manus_recurring_ops_prompt.md` | Periodic low-noise operational check-in prompt for monitoring and escalation |

These prompts are intended to make handoffs explicit, preserve context across sessions, and keep the continue/deny approval model consistent.

# Think Ecosystem Project Map

The Think ecosystem is organized as a small but intentionally separated system. The brand umbrella is **ThinkEdu**. Under that umbrella, each repository has a distinct job so product work, operating logic, and public founder identity do not become tangled.

## Structure overview

| Layer | Name | Purpose | Repository / URL |
|---|---|---|---|
| Umbrella brand | ThinkEdu | Parent category for AI-powered education products and initiatives | Brand layer |
| Product | ThinkRN | NCLEX preparation application and proof funnel | `uyhlop/thinkrn` · [thinkrn-zeta.vercel.app](https://thinkrn-zeta.vercel.app) |
| Operating layer | Think OS | Multi-agent orchestration, prompts, handoffs, and founder operating reference | `uyhlop/think-os` |
| Founder hub | ray.kosgei | Permanent links page for bio traffic and ecosystem routing | `uyhlop/ray-kosgei` |
| Monetization | Patreon | Build-in-public support and learning access | [patreon.com/ThinkEdu](https://patreon.com/ThinkEdu) |
| Social channel | Instagram | Public-facing top-of-funnel and founder updates | [@think.bsn](https://instagram.com/think.bsn) |
| Contact channel | Gmail | Founder inbox and operational updates | ray.kosgei1@gmail.com |
| Code identity | GitHub | Source control, project visibility, and technical proof | [uyhlop](https://github.com/uyhlop) |

## Connection model

ThinkEdu is the parent frame. **ThinkRN** is currently the main execution vertical and public product. **Think OS** explains how the work gets organized and how multiple agents help Ray build and operate the system. **ray.kosgei** serves as the public routing layer, especially for Instagram bio traffic, so visitors can move cleanly from Ray’s founder identity to the product, proof material, support channels, and build-in-public story.

## Current directional logic

| From | To | Why it matters |
|---|---|---|
| Instagram bio | ray.kosgei | Creates one stable entry point for all traffic |
| ray.kosgei | ThinkRN app | Sends users to the main product |
| ray.kosgei | ThinkRN proof and ambassador pages | Supports trust-building and growth conversion |
| ray.kosgei | Think OS | Shows how the system is being built |
| ray.kosgei | Patreon | Converts interested followers into supporters |
| GitHub profile | ThinkRN and Think OS repos | Shows technical execution and project separation |

## Why the split matters

This structure keeps the ecosystem legible. Product code remains inside **ThinkRN**. Operational logic and prompt architecture live inside **Think OS**. Founder-facing routing and public links live inside **ray.kosgei**. That separation gives Ray a cleaner story, less repository confusion, and a more durable foundation for future ThinkEdu subcategories.

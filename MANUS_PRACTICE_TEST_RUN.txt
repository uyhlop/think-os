"""

Mission:
- Simulate the daily ThinkRN Step 1 pipeline.
- Prove whether generated question outputs are clinically grounded and aligned to course objectives.

   - Load the practice exam set and objective map.
   - List missing fields before continuing.

   - For each item, explicitly map to objective_id and objective_text.

     b) answer key mismatch,

     d) objective cannot be identified,
     e) unsupported clinical claim.

   - Output event names and payload schema only:
     exam.item.scrubbed
     exam.item.objective_mapped
     exam.item.fake_risk_flagged
     exam.item.real_candidate_confirmed

6. Report
   - Return:
     A) Counts: total, real_candidate, fake_risk, needs_human_review
     B) Top 5 failure patterns
     C) Table of flagged items with reason
     D) Next 3 actions before production
7. Handoff Memory Update
   - Draft updates for memory/PROJECT_HANDOFF_MEMORY.md and memory/NEXT_WAKE_STEPS.md
   - Include exactly what to run first when I wake up.

Constraints:
- Original wording only.
- No copyrighted test bank phrasing.
- No invented pharmacology/pathophysiology claims.
